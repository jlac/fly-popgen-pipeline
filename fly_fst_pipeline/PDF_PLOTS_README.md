# Editable vector PDF plot outputs

All plots generated by the pipeline use PDF rather than PNG, preserving vector geometry suitable for Adobe Illustrator. The PDF backend embeds TrueType fonts (type 42) to improve text editability, subject to font availability on your system.

Outputs:
- `plots/pairwise_fst_heatmap.pdf`
- `plots/fst_scan_*_vs_*.pdf`
- `branch_stats/w*_s*/*.pdf`
- `pbsnj/w*_s*/EA.pbsnj.pdf` (and other populations)
- `enrichment/w*_s*/enrichment.pdf` (depending on chosen outdir)

CSV and TSV formats and statistical calculations are unchanged. Existing PNG files from old runs are not deleted or converted. New PDF plots require rerunning the corresponding plotting stage; to regenerate PBSnj scans without recomputing FST, call `python fly_fst_pipeline/pbsnj.py --outdir PBSnj_out --focal EA --populations EA,ED,SP,ZI,UG,FR,CO --genes dmel-all-no-analysis-r5.57.gff --peak-labels 5`. The FST heatmap/scans are normally generated by the full `fly_fst.py` analysis; other plots are produced at their respective stages.

**Note:** PDF plots preserve paths and embedded text, but some objects (e.g. highly dense heatmaps) may be composed of many paths or rasterized by Matplotlib depending on plot methods. No code paths in this release deliberately rasterize data.
